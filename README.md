# Top_200_Billionaires_Wealth_Analysis_Using_SQL
Global Billionaire Wealth Analysis Using SQL

Project Overview

This project explores the world’s top 200 billionaires using SQL and SQLite. It examines wealth distribution, billionaire demographics, country-level wealth concentration, and industry representation.

The project was completed as part of my data analytics learning journey with FadaQa.

Objectives

* Analyse the wealth distribution of the world’s richest individuals.
* Identify countries with the highest concentration of billionaire wealth.
* Examine billionaire demographics, including age distribution.
* Identify industries with the highest number of billionaires.
* Compare average and total net worth across countries and industries.

Tools Used

* SQLite
* DB Browser for SQLite
* SQL
* GitHub

SQL Skills Demonstrated

* SELECT and WHERE
* ORDER BY and LIMIT
* DISTINCT
* Aggregate functions (COUNT, SUM, AVG, MAX, MIN)
* GROUP BY and HAVING
* Subqueries
* CASE WHEN
* BETWEEN and IN

Project Questions

The analysis addresses 44 practical SQL questions, progressing from basic queries to more advanced analytical questions.

Project Structure

* sql/: SQL scripts containing the analytical queries.
* dataset/: Dataset used for the analysis.
* screenshots/: Screenshots of query results.

Learning Outcome

This project strengthened my practical understanding of SQL querying, data aggregation, filtering, grouping, and analytical thinking.
